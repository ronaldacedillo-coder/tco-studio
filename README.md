# MBT TCO Studio

HVAC total cost of ownership studies for MBT (Midea VC Max) vs other VRF brands.

Sign in with your MBT Pipeline account. Studies are stored in the MBT Pipeline Supabase project (tables tco_studies, tco_brands, tco_brand_models) with row-level security: each person sees only their own studies; the NSM and the Commercial AC Head see all.

Hosted on GitHub Pages from this repo (branch main, folder /).
